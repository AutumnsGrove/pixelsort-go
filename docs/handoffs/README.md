# Handoffs

One file per stop, so a reader who has seen none of the session can resume. Named `<date>-<slug>.md`.
Committed, never edited after the fact; follow-ups go in a new file or a new section at the bottom.

A handoff has these sections:

- **Where this is.** What is true now (what exists, what is tested, what is published).
- **What exists.** An inventory, so nothing has to be rediscovered.
- **What I did.** Short and concrete.
- **What I need.** The exact decisions, keys or approvals, with a recommendation where there is one.
- **What happens next.** What resumes once those are answered.
- **Risks.** What could go wrong, and how it was bounded.
- **Gotchas.** Things that bit us, so they do not bite twice.
